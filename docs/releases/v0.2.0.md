# 聊析 0.2.0

将微信合并聊天记录整理为一个文件夹，内含 Markdown、照片、视频和文档。

## 直接下载

- [macOS 通用版 DMG](https://github.com/liyouran0820/liaoxi/releases/download/v0.2.0/ChatArchive-macOS-universal.dmg)：macOS 14+，支持 Apple Silicon 与 Intel；打开后将“聊析”拖到 Applications。
- [macOS ZIP 备用下载](https://github.com/liyouran0820/liaoxi/releases/download/v0.2.0/ChatArchive-macOS-universal.zip)
- [Windows x64 独立 EXE](https://github.com/liyouran0820/liaoxi/releases/download/v0.2.0/ChatArchive-Windows-x64.exe)：Windows 10/11，双击运行，无需安装 Python。
- [Windows ZIP 备用下载](https://github.com/liyouran0820/liaoxi/releases/download/v0.2.0/ChatArchive-Windows-x64.zip)
- [SHA-256 校验文件](https://github.com/liyouran0820/liaoxi/releases/download/v0.2.0/SHA256SUMS.txt)

## 更新

- Markdown 与实际附件平铺到一个总文件夹，整夹移动后相对链接仍有效。
- 区分消息正文与灰色引用原文，Markdown 开头给出供 LLM 理解的样式说明。
- 尝试通过微信可见菜单保存附件，提供“补充附件”多选入口，支持照片、视频及文档。
- 同名文件自动编号，相同内容去重，复制后进行 SHA-256 校验；缺失附件记录在文末。
- Windows 使用本地系统 OCR 与 UI Automation，支持窗口选择、自动滚动与停止。

## 系统与签名

- macOS 包使用 Developer ID Application 签名，当前未完成 Apple 公证；首次打开可能受到系统安全策略限制。
- Windows EXE 当前没有 Authenticode 签名，下载或启动时可能显示 SmartScreen 提示。
- Windows OCR 需要已安装中文或英语语言功能。Mac 需要辅助功能和屏幕录制权限。
- 微信不同版本的菜单可访问性不同，自动保存无法保证取得每一个附件。过期或不可读附件请在微信中另存后补充。CI 自检不代表真实微信附件下载已经在所有版本验收。

处理默认在本机完成，不读取微信数据库或登录凭据，不上传聊天内容。
