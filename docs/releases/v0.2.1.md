# 聊析 0.2.1

- 照片与视频区域先遮罩，再识别聊天正文，不将媒体内部的文字转写进 Markdown。
- 开始提取时创建与 `.md` 同名的文件夹，附件从保存时就进入该文件夹；Markdown 用“类型：实际文件名”的相对链接引用。
- 中断时保留已保存附件，并在 Markdown 标注提取未完成。
- 增加微信自绘菜单的可见命令识别，修正只激活主程序而未置前目标记录窗口的问题。
- 修正没有弹出菜单时盲发 Esc 的问题；保存面板路径等待改为状态确认，隐藏扩展名使用唯一前缀避免覆盖提示。
